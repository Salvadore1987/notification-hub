# ADR-0016. OpenAPI пишется вручную и проверяется тестом, а не генерируется из кода

| | |
|---|---|
| **Статус** | Принято · временное (до релиза springdoc под Boot 4) |
| **Дата** | 08.08.2026 |
| **Требования SRS** | IR-03, §8.2, UI-02 |
| **Связанные решения** | [ADR-0014](ADR-0014-shared-inbound-contract.md), [ADR-0017](ADR-0017-admin-bff-separate-api.md), [ADR-0033](ADR-0033-frontend-stack.md) |

## Контекст

IR-03 требует спецификацию OpenAPI 3.1 как артефакт поставки и говорит «генерируется из кода». Стандартный
инструмент для этого — springdoc — на момент реализации не имеет релиза под Spring Boot 4. Ждать нельзя: контракт
§8.2 нужен системам-источникам для интеграции, а админский контракт — фронту, который генерирует из него типы.

## Решение

Контракт написан вручную и лежит рядом с кодом, который его реализует:

- `/api/v1` — `adapter/in/rest/src/main/resources/openapi/`;
- `/api/admin/v1` — `adapter/in/admin/.../openapi/` (`comm-hub-admin-v1.yaml`).

Честность контракта поддерживается **тестом** (`OpenApiContractTest`), а не дисциплиной: он сверяет описанные
операции с тем, что действительно опубликовано приложением. Разошлось — сборка красная.

Фронт генерирует типы из админского контракта (`npm run generate:api`, результат коммитится), поэтому расхождение
между панелью и BFF становится ошибкой компиляции TypeScript.

**Решение помечено как временное.** Появится релиз springdoc под Boot 4 — генерация заменит ручной файл;
проверяющий тест при этом остаётся полезным (он превращается в проверку, что сгенерированное соответствует
опубликованному).

## Альтернативы

- **Отложить контракт до появления генератора.** Блокирует интеграцию источников и разработку фронта.
- **Взять springdoc из предрелизной ветки.** Зависимость без релиза в банковской поставке — риск, несопоставимый
  с экономией.
- **Писать вручную без проверяющего теста.** Ровно тот случай, когда документация расходится с кодом молча.

## Последствия

**Положительные.** Контракт существует с первого дня и читается как контракт, а не как отражение сигнатур
контроллеров: примеры, коды ошибок IR-01 и заголовки описаны так, как нужно интегратору. Фронт типобезопасен.

**Цена.** Изменение endpoint требует правки двух файлов — кода и yaml. Тест напоминает об этом сразу, поэтому
цена оплачивается в момент правки, а не в момент интеграции.

## Как нарушение будет замечено

`OpenApiContractTest` в `./gradlew build`. Со стороны фронта — рассинхрон типов после `npm run generate:api`.
